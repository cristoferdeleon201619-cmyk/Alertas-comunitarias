Activa tu ubicación para reportar

Cuando toques «Usar mi ubicación actual», tu teléfono te va a preguntar si permites compartir tu ubicación. Toca Permitir: sin eso no se puede marcar el punto exacto de la alerta.

Tu navegador ya tiene la ubicación bloqueada para esta página, por eso ya no vuelve a preguntar. Actívala así:

En Android (Chrome)

  1. Toca el candado o el icono de ajustes en la barra de direcciones.
  2. Toca «Permisos» y luego «Ubicación».
  3. Elige «Permitir» y vuelve a esta página.

En iPhone (Safari)

  1. Abre Ajustes → Safari → Ubicación y elige «Preguntar» o «Permitir».
  2. O toca el botón «aA» en la barra de direcciones → «Ajustes del sitio web» → Ubicación → Permitir.
  3. Vuelve a esta página y toca de nuevo el botón de ubicación.

Cómo publicar esta página para que la use la gente

Esta es la versión lista para publicar: una sola página web, sin tienda de aplicaciones. Se hospeda gratis en GitHub Pages, igual que hiciste con el juego, y cualquiera la abre desde el navegador de su teléfono.

  1. Guarda esta página como index.htmlEs el único archivo que necesitas: el mapa, los botones y el formulario ya van dentro.
  2. Crea un repositorio en github.comEntra a tu cuenta, crea un repositorio nuevo (por ejemplo alertas-comunitarias) y sube el archivo index.html suelto, sin meterlo en carpetas.
  3. Activa PagesEn el repositorio: Settings → Pages → rama main, carpeta raíz (/root) → Save.
  4. Comparte tu enlaceQuedará como tu-usuario.github.io/alertas-comunitarias. Ese enlace es el que compartes por WhatsApp o Facebook para que la comunidad lo abra.
  5. El permiso de ubicación sale soloComo GitHub Pages usa conexión segura (https), la primera vez que cada persona toque «Usar mi ubicación actual», Chrome o Safari le preguntará «¿Permitir ubicación?» y con tocar Permitir ya puede reportar. No hay que instalar nada.
Base de datos ya conectada: los reportes se comparten Esta página ya está conectada a tu base de datos de Firebase, así que lo que una persona publique lo ven todas las demás, y las alertas se siguen borrando solas a las 4 horas. Importante: las reglas de prueba vencen en unos 30 días Si creaste la base de datos en «modo de prueba», Firebase cierra el acceso cuando pasen unos 30 días y las alertas dejarían de compartirse. Antes de que eso pase, entra a tu proyecto en la consola de Firebase → Realtime Database → pestaña «Reglas» y déjalas así, para que solo se pueda leer y escribir en las alertas: { "rules": { "alerts": { ".read": true, ".write": true } } }
